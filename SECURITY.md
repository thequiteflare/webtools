# Security Policy

## Privacy & Security Guarantee

**Webtools** is engineered as a zero-knowledge, 100% client-side web application. All data transformations, file decodings, and conversions occur in the sandboxed JavaScript/WebAssembly runtime of the user's browser. No user documents or inputs are sent to remote servers.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or potential privacy leak (such as an unintended external request or unsafe script execution):

1. **Please do not disclose it publicly** via GitHub Issues or discussions.
2. Email the maintainers directly or submit an advisory via GitHub Security Advisories.
3. Include detailed steps to reproduce the issue and any relevant browser environment details.

We take security and user privacy seriously and will respond to valid disclosures promptly.
